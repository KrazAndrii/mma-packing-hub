# MMA Packing Hub

Хаб-інструмент для автоматичної генерації гравіювання, специфікацій, юридичного маркування (стікер КМ) та штрихкодів — на основі специфікацій від фабрики.

## Що вміє

1. **Генератор гравіювання (SVG + DXF)** — текст перетворюється в криві (контури), файл готовий для лазера/фрезера. Один клік — завантаження.
2. **Compliance Checker** — перевіряє суму потужностей портів проти Total Output, обов'язкові сертифікати (CE, RoHS, RED), заборонені символи, контрольну цифру EAN-13, обов'язкові поля маркування. Правила редагуються прямо в інтерфейсі.
3. **Штрихкод EAN-13** — валідація + векторний SVG і PNG високої роздільності.
4. **Мультибренд** — профілі Ridea, Yoki, iNobi з окремими правилами, імпортером і знаками.
5. **Переклади 6 мов** (EN, UA, RO, BG, ES, PL) + AI-генератор маркетингових буллетів (опційно, безкоштовний ключ Google AI Studio).

## Стандарт гравіювання

Реалізовано згідно з внутрішнім стандартом:

- Лише прямий слеш `/`; у В/А без пробілів (`5V/3A`), між словами — з пробілами (`Вхід / Вихід`).
- Два режими: **Повні пробіли** (коробки, документи) і **Компактний** (АЗУ, TWS).
- Незмінний порядок блоків: Модель → Вхід → Вихід → Технології → Знаки → Made in China → Партія.
- Знаки: `[CE] [RoHS] [Урна] [Трилистник] [Петля Мёбиуса]`.
- Винятки за тригерами: акумулятор (mAh/Wh), «Режим», ККД `≥65%`, Data Transfer, Driver Size/Codecs, Magnetic Pull Force.

```bash

```

## ШІ (опційно)

Без ключа працює шаблонний генератор буллетів. Для якіснішого ШІ-варіанту:

- Отримати безкоштовний ключ на https://aistudio.google.com/apikey
- Вставити його у вкладці «Переклади» (зберігається лише у браузері), або
- Додати змінну середовища `GEMINI_API_KEY` у Vercel

## Структура правил

Правила валідації зберігаються у профілі бренду (`src/lib/profiles/index.ts`) і редагуються в UI. Типи перевірок: `sum_ports_equals_total`, `required_certs`, `required_fields`, `forbidden_chars`, `ean_checksum`, `range`, `regex`.
